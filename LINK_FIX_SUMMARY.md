# Link Fix Summary

## What Was Fixed

All navigation links pointing to `https://www.architecturalecologies.cca.edu` have been converted to relative local paths in **220 HTML files**.

### Examples of fixes:
- `href="https://www.architecturalecologies.cca.edu/about"` → `href="about.html"`
- `href="https://www.architecturalecologies.cca.edu/research/ecopoesis"` → `href="research/ecopoesis.html"`
- `href="https://www.architecturalecologies.cca.edu"` → `href="index.html"`

### What Was NOT Changed (Correctly)
Meta tags and JSON-LD structured data still contain canonical URLs:
- `<meta property="og:url" content="https://www.architecturalecologies.cca.edu"/>`
- `<meta name="twitter:url" content="..."/>`
- JSON-LD schema.org data

These SHOULD remain as canonical URLs for SEO and social sharing purposes.

## Why Did wget Leave Some Links Unconverted?

The issue with wget's `--convert-links` is likely due to one or more of these factors:

1. **JavaScript-Rendered Content**: If the navigation menu on the seed page (index.html) was generated or modified by JavaScript after the page loaded, wget may have saved the page before the JavaScript executed. This is common with Squarespace sites.

2. **Base Tag Issues**: If the page has a `<base href="">` tag (which this site does), it can confuse wget's link conversion logic.

3. **Timing**: wget's `--convert-links` converts links AFTER downloading all files. If some files failed to download or were skipped, related links might not get converted.

4. **Dynamic URLs**: Links generated by client-side routing or AJAX may not be recognized by wget's static HTML parser.

## Solutions for Future wget Archives

### Better wget command:
```bash
wget --mirror \
     --convert-links \
     --adjust-extension \
     --page-requisites \
     --no-parent \
     --no-check-certificate \
     --wait=1 \
     --random-wait \
     --execute robots=off \
     --user-agent="Mozilla/5.0" \
     --domains=$DOMAIN \
     https://$DOMAIN
```

Additional flags that might help:
- `--wait=1 --random-wait`: Reduces rate limiting issues
- `--execute robots=off`: Ensures all pages are downloaded
- `--user-agent="Mozilla/5.0"`: Mimics a real browser

### Alternative: Post-download link fixing
Run a script like `fix_all_links.sh` (created in this fix) after wget completes.
